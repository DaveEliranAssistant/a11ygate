Run it in CI now

The CLI is on npm as @qe-atlas/a11ygate@0.2.0. The GitHub Action is listed on the GitHub Marketplace as A11yGate axe-core Regression Gate by DaveEliranAssistant. The browser demo is on this page. The waitlist does not gate any of them.

The CLI and the Action read scan files inside your own job and send nothing to A11yGate. With comment: true, the Action posts its summary to your pull request.

1. Write axe JSON from Playwright

In the project you are auditing:

npm install --save-dev @playwright/test @axe-core/playwright

Save this as tests/a11y.spec.ts and change the URL. Write one file per page.

import { test } from '@playwright/test';
import AxeBuilder from '@axe-core/playwright';
import { mkdir, writeFile } from 'node:fs/promises';

test('home', async ({ page }) => {
  await page.goto('https://example.com/');
  const results = await new AxeBuilder({ page }).analyze();
  await mkdir('a11y-results', { recursive: true });
  await writeFile('a11y-results/home.json', JSON.stringify(results, null, 2));
});
2. Run the CLI
npx playwright install chromium
npx playwright test
mkdir -p a11y
npx @qe-atlas/a11ygate --current a11y-results/home.json --update-baseline a11y/baseline.json
npx @qe-atlas/a11ygate --current a11y-results/home.json --baseline a11y/baseline.json

With no baseline, every finding is new. The --update-baseline run writes the file and exits 1 if the scan has a serious or critical finding. The --baseline run exits 1 only when a new one appears. Commit the file, and the same command works in any CI job.

3. Add the GitHub Action

Put this in .github/workflows/accessibility.yml. Let the Playwright test write JSON and let A11yGate be the gate. Do not also assert violations.length === 0 in that test, or the job fails before the summary is posted.

name: Accessibility
on:
  pull_request:

permissions:
  contents: read
  issues: write

jobs:
  a11y:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: npm ci
      - run: npx playwright install --with-deps chromium
      - run: npx playwright test
      - uses: DaveEliranAssistant/a11ygate-action@v1
        with:
          current: |
            a11y-results/home.json
          baseline: a11y/baseline.json
          threshold: serious
          comment: true

Record the Action's baseline on the runner. Do not reuse the file from step 2. The Action at v1 also compares scan configuration and browser environment, so a baseline from CLI 0.1.0 or from your laptop stops it with INCOMPLETE and exit 2.

For the first run, replace the A11yGate step with these steps:

      - run: mkdir -p a11y
      - uses: DaveEliranAssistant/a11ygate-action@v1
        continue-on-error: true
        with:
          current: |
            a11y-results/home.json
          update-baseline: a11y/baseline.json
      - uses: actions/upload-artifact@v4
        with:
          name: a11y-baseline
          path: a11y/

Download the a11y-baseline artifact, review it, and commit a11y/baseline.json. Then restore the A11yGate step above.
