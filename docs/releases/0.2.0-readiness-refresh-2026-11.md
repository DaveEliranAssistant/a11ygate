## Breaking-change notes

Re-checked 2026-11-28 at `4940bb4`: A11Y-R76 to R80 add no upgrade note (R78 adds the new `outreach kit` command and the opt-in `prospect --outreach-data` flag; R76 and R80 change the web app and scripts, not the CLI; R77 is docs). From the [CHANGELOG upgrade notes](../../packages/cli/CHANGELOG.md#upgrade-notes) (relative to a `main` build at `a215b6f`; the 2026-11-14 [upgrade notes](0.2.0-upgrade-notes.md) still describe published 0.1.0 → `a215b6f`):

- `review` without `--list` or `--group` and without a terminal now exits 2; Ctrl+C mid-prompt exits 130 (A11Y-R51).
- HTML report v2 is the default; `--report-version 1` restores the previous HTML (A11Y-R28).
- `.a11ygate.yml` keys now apply at runtime, with precedence CLI flag / Action input > `A11YGATE_*` > YAML > default (A11Y-R33).
- SARIF, JUnit and GitLab Code Quality exports honour active review decisions, so dashboards may count fewer failures (A11Y-R43).
- Fingerprint baselines may contain `groupDecisions` and `history[]`; evidence-pack manifests may record `commit.committedAt` and `commit.branch` (A11Y-R39, R44, R48).
- Scan JSON `en301549` can be `null` for WCAG 2.2-only criteria (A11Y-R59).
- The default 20-state interaction cap also applies to `--auto-interactions` (A11Y-R45); Lighthouse snapshots are serialized (A11Y-R47); a configured `auth.check` replaces heuristic login detection (A11Y-R52); `--no-screenshots` writes a marker file (A11Y-R50).
- Stricter malformed-input checks for `.a11ygate.yml`, evidence-pack zips and `--storage-state` cookies (A11Y-R61).
- The Azure DevOps template uses `UseNode@1` (A11Y-R35).
- Scan Markdown without a baseline now includes the disclaimer (A11Y-R73).
- JSON reports and evidence-pack manifests record `releaseStatus: "released"` instead of `"unreleased-source-build"`, and `a11ygate --help` no longer calls the build source-only (A11Y-R22). Consumers that read `releaseStatus` must accept the new value.
